# Security policy

This tool is read-only and never sends exploit traffic. If you find a way it could
harm a system, leak data, or give a wrong "patched" verdict, please report it
privately at https://github.com/msoni11/msphp2shell/security/advisories/new
rather than in a public issue.

For the PHP2Shell vulnerabilities themselves, see the official PHP advisory:
https://www.php.net/archive/2026.php#2026-10-21-5
